# SKY Traders — SKY Coconuts

> Premium Wholesale Coconut Trading & Export Website for SKY Traders, Udumalpet, Tamil Nadu, India.

![SKY Traders Brand](public/assets/sky_traders_official_logo.jpg)

## Overview

A modern, high-performance web application designed for **SKY Traders** (Brand Identity: **SKY Coconuts**), wholesale coconut traders and exporters located in the coconut belt of **Udumalpet, Tamil Nadu, India**.

## Key Features

- **Wholesale Coconut Products:**
  - **Fully Husked Coconut:** Clean, peeled mature coconuts for high-volume commercial supply.
  - **Semi-Husked Coconut:** Natural fiber protection ideal for transit and export handling.
  - **Coconut Shell:** Hard mature coconut shells for activated carbon and industrial use.
  - **Copra:** Sun-dried and well-cured copra for wholesale oil extraction and milling.
- **Direct WhatsApp Integration:** Automated formatted messages for wholesale pricing, volume quotes, and container orders sent directly to `+91 63808 49351`.
- **Accurate Geographical Navigation:** Interactive location card and Google Maps directions targeting the official SKY Traders Udumalpet facility.
- **Responsive Architecture:** Fully mobile-optimized with smooth navigation drawers, quick touch actions, and accessible color contrast.

## Tech Stack

- **Framework:** React 18 + Vite + TypeScript
- **Styling:** Tailwind CSS (Custom agricultural commodity luxury palette)
- **Icons:** Lucide React
- **Animations:** Framer Motion
- **Deployment Ready:** Optimized static build (`dist`)

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm / pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/vishnupriyac240307/sky-traders-website.git
cd sky-traders-website

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
